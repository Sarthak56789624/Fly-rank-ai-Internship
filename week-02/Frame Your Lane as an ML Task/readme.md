# Frame Your Lane as an ML Task

## Overview

**Frame Your Lane as an ML Task** is an activity that focuses on identifying a real-world problem from a chosen domain and framing it as a Machine Learning (ML) task. The exercise helps in understanding how business or practical problems can be translated into ML problems by defining objectives, inputs, outputs, and suitable learning approaches.

## Objective

* Understand how to formulate real-world problems as Machine Learning tasks.
* Identify the type of ML problem (Classification, Regression, Clustering, Recommendation, etc.).
* Define the input features and expected outputs.
* Select appropriate evaluation metrics and machine learning algorithms.

## Activity Description

In this exercise, a problem from a specific domain is selected and analyzed to determine how Machine Learning can be applied. The task involves identifying the business objective, understanding the available data, defining the target variable, and choosing the most suitable ML approach for solving the problem.

## Workflow

1. Select a real-world problem from your domain of interest.
2. Define the problem statement.
3. Identify the input features (independent variables).
4. Determine the target variable (output).
5. Classify the problem type (Classification, Regression, Clustering, etc.).
6. Choose suitable machine learning algorithms.
7. Define evaluation metrics to measure model performance.

## Learning Outcomes

After completing this activity, you will be able to:

* Translate business problems into ML problems.
* Distinguish between different types of machine learning tasks.
* Identify relevant datasets, features, and target variables.
* Select appropriate algorithms and evaluation methods for a given problem.
