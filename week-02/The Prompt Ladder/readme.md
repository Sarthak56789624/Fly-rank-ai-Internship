# The Prompt Ladder

## Overview

The Prompt Ladder is an exercise that demonstrates how the quality of AI-generated responses improves as prompts become more specific and detailed. Instead of asking a vague question, each level adds more context, constraints, and expected output, resulting in more accurate and useful responses.

## Objective

* Understand the importance of prompt engineering.
* Compare AI responses generated from different levels of prompts.
* Learn how adding context and clear instructions improves output quality.

## Prompt Levels

### Level 1 – Basic Prompt

A simple prompt with minimal information.

**Example:**

> Explain machine learning.

### Level 2 – Contextual Prompt

Provides additional context to guide the AI.

**Example:**

> Explain machine learning to a first-year engineering student.

### Level 3 – Detailed Prompt

Includes context, audience, constraints, and expected format.

**Example:**

> Explain machine learning to a first-year engineering student in simple language. Include the definition, types of machine learning, real-world applications, and a short example. Keep the explanation under 300 words.

## Key Learnings

* Clear prompts generate more relevant responses.
* Providing context helps the AI understand the intended audience.
* Specifying format, length, and constraints improves response quality.
* Prompt engineering is an essential skill for effectively using AI tools.
